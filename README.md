# Лабораторная работа № 3 — «Доска публикаций»

Клиентское приложение на HTML + CSS + JavaScript.
Работа с асинхронным JavaScript (fetch, async/await) и REST API (JSONPlaceholder).

**Автор:** *Шагаева Мария БПИ-23-РП-3*

## Запуск

Открыть `index.html` в любом современном браузере.

## Файлы

Файл         | Назначение
`index.html` | разметка: кнопки, форма, список
`style.css`  | оформление
`app.js`     | логика запросов, валидация, рендер

## Реализовано

**Интерфейс.**
Кнопка «Загрузить публикации», список публикаций, форма создания (Заголовок, Текст), область сообщений.

**GET-запрос.**
По нажатию на кнопку выполняется `fetch` к `https://jsonplaceholder.typicode.com/posts?_limit=5`. Проверяется `response.ok`, данные рендерятся через `textContent`.

**POST-запрос.**
Форма отправляется через `preventDefault`. Валидация на пустые строки (trim).
Отправляется JSON `{ title, body, userId: 1 }`. В случае успеха выводится сообщение с ID и заголовком.

**Обработка ошибок и состояний.**
Используется `try/catch/finally`. Кнопки блокируются на время запроса. При ошибке (например, 404 при замене URL) выводится красное сообщение, кнопка снова становится активной.

## Проверка

Отправка пустых полей                     | Ошибка валидации
Отправка корректных данных                | Успешный ответ (HTTP 201), данные на странице
